# Лабораторная работа № 6. Функции

## Автор

Хан Кирилл, ПИ-261. Вариант 26.

## Цель

Научиться передавать массив и его размер в функцию, отделять вычисления от ввода и вывода и использовать одну функцию для разных данных.

## Задача

Даны массивы G и H одинакового размера n. Построить массив F по формуле F[i] = G[i] / H[i]. Найти суммы элементов G, H и F.

В программе G соответствует `numeratorValues`, H — `denominatorValues`, F — `quotientValues`. Функция `divideValues` заполняет F, а функция `sumValues` вызывается три раза для разных массивов. Ввод, проверка исходных данных и вывод находятся в `main`.

## Ввод

Сначала введите целое n от 1 до 100, затем n чисел массива G и n чисел массива H. Модуль каждого исходного элемента не превышает 1000. Элементы H должны быть ненулевыми. Дробная часть отделяется точкой. Числа можно разделять пробелами или переносами строк.

Программа не печатает приглашения ко вводу. При ошибке чтения, недопустимом размере, нарушении диапазона или нулевом знаменателе она выводит `INVALID` и завершается. Проверка всех знаменателей выполняется до первого деления. Ограничение ±1000 относится к исходным массивам G и H, а не к полученному F.

## Вывод

Строка `F:` содержит элементы полученного массива. Далее выводятся `Sum G`, `Sum H` и `Sum F` — три суммы. Используется обычная точность вывода `cout`; дробные результаты могут отображаться с округлением.

## Пример

Ввод:

```text
3
6 -8 0
2 -4 5
```

Вывод:

```text
F: 3 2 0
Sum G: -2
Sum H: 3
Sum F: 5
```
